Общая архитектура (Двойная буферизация)

Игра работает по принципу двух матриц (буферов):

    grid — текущее поколение (то, что мы видим на экране).

    next — следующее поколение (матрица, в которую мы записываем изменения, чтобы они не влияли на расчеты соседних клеток в текущем кадре).

1. int main(void)

Это главная функция, которая связывает всё воедино. Она отвечает за жизненный цикл программы: инициализацию, главный игровой цикл и безопасное завершение.

За что отвечает:

    Инициализация матриц: Создает массивы grid и next размером 25x80, заполняя их нулями.

    Чтение файла: Вызывает init_grid, чтобы прочитать стартовую карту из перенаправленного файла (< pattern1.txt).

    Перехват клавиатуры (Хаки для ncurses):

        freopen("/dev/tty", "r", stdin) — после того как файл карты закончился (достигнут EOF), эта команда принудительно переключает stdin на чтение физической клавиатуры.

        clearerr(stdin) — сбрасывает флаг ошибки "Конец файла", чтобы ncurses не думал, что ввод закончен навсегда.

    Настройка ncurses:

        initscr() — стартует режим отрисовки.

        noecho() — отключает печать нажимаемых клавиш на экране.

        cbreak() — отключает буферизацию строк (чтобы программа реагировала на клавиши сразу, не дожидаясь нажатия Enter).

        curs_set(FALSE) — прячет мигающий курсор терминала.

        nodelay(stdscr, TRUE) — делает getch() неблокирующим (программа не ждет нажатия клавиши, а летит дальше, если ничего не нажато).

    Главный игровой цикл (while(running)):

        Считывает все нажатые клавиши через while ((ch = getch()) != ERR).

        Изменяет переменную speed (задержку) или меняет running на 0, чтобы выйти.

        Вызывает функции отрисовки и вычисления следующего кадра.

        Останавливает программу на долю секунды usleep(speed * 1000) для регулировки скорости (FPS).

    Завершение: endwin() корректно закрывает режим графики и возвращает терминал в нормальный вид.

2. static void init_grid(int grid[HEIGHT][WIDTH])

За что отвечает: Загружает первое поколение клеток из файла или стандартного ввода.

Как работает:

    В цикле while читает по одному символу через getchar(), пока не кончится файл (EOF) или пока не заполнятся все 25 строк (HEIGHT).

    Если встречает символ переноса строки \n, переходит на новую строку матрицы (r++) и сбрасывает счетчик столбцов (c = 0).

    Если встречает символ '1', записывает в матрицу 1 (живая клетка). Все остальные символы (пробелы, '0', буквы) записывает как 0 (мертвая клетка).

3. static void draw_grid(int grid[HEIGHT][WIDTH])

За что отвечает: Выводит матрицу на экран терминала с помощью графики ncurses.

Как работает:

    erase() — полностью очищает экран от предыдущего кадра.

    Двойной цикл проходит по каждой координате поля.

    mvaddch(i, j, ...) — ставит курсор в координаты (i, j) и печатает символ. Если в матрице 1, печатается константа ALIVE (буква 'O'). Если 0, печатается DEAD (пробел).

    mvprintw(...) — печатает строку с подсказкой по управлению в самой нижней левой строке экрана.

    refresh() — применяет все изменения. (До вызова refresh всё рисуется в скрытой памяти, а эта функция "выплескивает" всё на экран разом — чтобы не было мерцания).

4. static int count_neighbors(int grid[HEIGHT][WIDTH], int y, int x)

За что отвечает: Самая важная математическая функция в игре. Считает, сколько живых соседей окружает конкретную клетку с координатами y и x.

Как работает:

    Два цикла dy и dx от -1 до 1 перебирают 9 клеток (саму клетку и 8 соседей вокруг неё).

    if (dy == 0 && dx == 0) continue; — исключает из подсчета саму клетку (y, x), чтобы она не посчитала саму себя за соседа.

    Тороидальное поле (Замкнутость пространства): Строчка (y + dy + HEIGHT) % HEIGHT — это математический трюк. Если клетка находится на самом верху (y=0), сосед сверху должен быть 0 - 1 = -1. Но индекса -1 в массиве нет. Формула делает так: (-1 + 25) % 25 = 24. Таким образом, сосед сверху берется из самого низа матрицы!

    Функция суммирует значения в соседних ячейках и возвращает это число (от 0 до 8).

5. static void update_grid(int current[HEIGHT][WIDTH], int next[HEIGHT][WIDTH])

За что отвечает: Применяет классические правила «Игры Жизнь» Джона Конвея для создания нового поколения клеток.

Как работает:

    Проходит двойным циклом по всем клеткам поля current.

    Для каждой клетки вызывает count_neighbors, чтобы узнать количество соседей (переменная n).

    Правила Конвея:

        Если клетка сейчас живая (current == 1): она выживает, только если соседей 2 или 3 (next = (n == 2 || n == 3)). Иначе умирает (записывается 0).

        Если клетка сейчас мертвая (current == 0): она оживает, только если вокруг ровно 3 соседа (next = (n == 3)).

    Результат записывается в массив next.

6. static void copy_grid(int dest[HEIGHT][WIDTH], int src[HEIGHT][WIDTH])

За что отвечает: Перезаписывает старое поколение клеток новым.

Как работает:

    Просто проходит двойным циклом по массивам и копирует каждое значение из массива src (источник, то есть наш next) в массив dest (назначение, то есть наш grid).

    После вызова этой функции в main, кадр считается полностью завершенным, старое состояние забывается, и цикл while может рисовать новую картинку.
